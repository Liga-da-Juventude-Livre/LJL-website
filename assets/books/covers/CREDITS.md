# Book covers: where each one came from

Covers belong to their publishers and are shown only to identify the books the Liga recommends. If a publisher asks for one to
be taken down, delete its `.jpg` here and run `node scripts/covers.mjs index`: the book falls back to a typeset cover on its own.
Several images came from a bookstore or book database because the publisher's own site did not offer a usable file. When a
publisher can send a press-kit image, replace it with `node scripts/covers.mjs add <slug> <file>`.
